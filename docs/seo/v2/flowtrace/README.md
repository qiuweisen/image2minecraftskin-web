# ChartMini v2 SEO Flowtrace

All task evidence created after the 2026-08-14 v2 workflow baseline belongs here.

Use one directory per task, for example:

`docs/seo/v2/flowtrace/chartmini-2026-08-14-task20-1-stocktwits-recovery/memory.md`

Each memory should record:

- target URL and v2 source file
- production baseline and observation date
- GSC evidence or explicit unavailable status
- Bing evidence or explicit unavailable status
- fresh SERP evidence
- internal-link and cannibalization findings
- Owner Gate decision
- planned and actual changes
- v2 architecture considerations
- validation commands/results
- deployment/indexing status
- next observation/action

Do not copy old-project task state into a v2 Flowtrace as current evidence.
